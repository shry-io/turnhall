How it works

Three steps, no accounts

  1. Install Turnhall Home on your Mac

    It runs your agents and keeps your projects, keys and files where they already are.

  2. Scan the QR code with Turnhall

    Pair your iPad or iPhone in a few seconds, straight from the Home window.

  3. Your tasks follow you

    Pick up the same conversations on any paired device, and answer when an agent needs you.

What you get

Built for how developers work with agents

⚙️Every engine

Claude, Cursor, Codex and Antigravity, side by side. Each task runs on its own engine, so you can pick the right tool for the job and switch without changing how you work.

🗂️Tasks and workspaces

A task agent coordinates several workspaces, collects their reports and keeps you across it all. Each task gets a readable summary, always labelled with who wrote it: “Summary by …”.

📁Project browser

Browse the file tree, read code with syntax highlighting, zoom into images and open PDFs and SVGs. Hold a file path in a reply to preview it without leaving the conversation.

✨Helpers

  • Summaries, proofreading, dictation and read aloud.
  • Bring your own models and keys.
  • Off means off: every helper can be switched off.

⌨️Terminal and file transfer

A real shell on your Mac, and drag-and-drop file transfer. Both work on your local network only, and both stay off until you allow them for each device.
